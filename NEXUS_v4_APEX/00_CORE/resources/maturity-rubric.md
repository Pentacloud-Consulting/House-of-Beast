## Maturity rubric (0–10 per layer)

[conf: RECOMMENDED]

### INTERFACE layer (06–08) — derived from UX/UI pre-delivery checklist

Score each item 0/1, total 10:

1. Layout uses responsive primitives (container queries / fluid spacing)
2. Component system uses token tiers (core/semantic/component)
3. Focus visible + keyboard navigation works end-to-end
4. ARIA patterns used correctly (no div-button anti-pattern)
5. Reduced motion support exists
6. Color contrast meets WCAG targets for key text
7. Forms have labels, errors, and help text
8. Loading states + empty states defined
9. Print view exists where relevant
10. No “magic CSS” overrides without tokens

### DELIVERY + GROWTH quick signals (heuristic)

- DELIVERY (19–20): CI/CD + rollback + SLO + RUM defined
- GROWTH (21–22): sitemap + hreflang + schema + llms.txt + entity plan defined
