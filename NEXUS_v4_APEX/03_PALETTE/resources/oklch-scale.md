## OKLCH scale generation (Module 02)

- Working space: OKLCH
- Each palette hue gets a **12-step scale**: 50/100/200/300/400/500/600/700/800/900/950 + surface step.
- Method: fix hue + chroma; walk lightness to create perceptually even steps.
- Semantics:
  - 50–200: surfaces
  - 400–600: interaction states
  - 700–950: text/ink
