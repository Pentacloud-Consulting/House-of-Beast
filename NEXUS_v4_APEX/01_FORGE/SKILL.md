## L1

- Output a PRD + acceptance criteria contract, not prose-only.

## L2 (Module 01 alignment: UX Brainstorm + IA)

- **Pre-design intelligence**: map business model, user intent matrix, JTBD, and emotional journey (arrival → decision).
- **IA depth**: build sitemap with purpose/keyword/funnel-stage/linking; enforce *no orphan pages*.
- **Tree testing prompts**: generate “can user find X from home with no visual cues?” prompts.
- **Navigation decision**: pick pattern by volume/hierarchy rules (simple nav vs mega menu vs sidebar etc.).
- **Content hierarchy protocol**: every page maps elements to one of: primary message, proof, detail, singular action.
- **Form/error states as first-class**: define default/focus/valid/invalid/disabled + skeleton/empty/error/recovery.
